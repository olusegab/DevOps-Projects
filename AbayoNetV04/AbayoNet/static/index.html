📦 Import / Export Hosts
↓ Export Hosts

Export all monitored hosts to a file. Use this to transfer hosts to another computer running AbayoNet, or as a backup.

JSON export preserves all host settings and can be imported directly into another AbayoNet instance. CSV is view-only.
↑ Import Hosts

Import hosts from a JSON export. Existing hosts (same IP) are skipped. New hosts start monitoring immediately.

📂
Click to select or drag & drop JSON file
Only AbayoNet JSON export files supported
📋 How to Transfer Hosts to Another Laptop
Step 1 — On this computer: click "Export as JSON" above and save the file
Step 2 — Copy the JSON file to the other laptop (USB, email, shared folder, etc.)
Step 3 — On the other laptop: install AbayoNet and start it (double-click START_ABAYONET.bat)
Step 4 — Log in as admin → go to Import / Export → click "Import" → select the JSON file
Step 5 — All hosts are imported and monitoring begins immediately ✅
