   YomiMark — Smart Bookmark Manager
   Chrome Extension Installation Guide
═══════════════════════════════════════════════════

HOW TO INSTALL
──────────────
1. Unzip this folder anywhere on your computer.
2. Open Chrome and go to:   chrome://extensions
3. Turn ON "Developer mode" (top-right toggle).
4. Click "Load unpacked".
5. Select the "YomiMark" folder (this folder).
6. The YomiMark icon (bookmark with Y) appears in your toolbar.

HOW TO USE
──────────
• Click the YomiMark icon in the toolbar to open your bookmark panel.
• Your existing Chrome bookmarks are loaded automatically on first open.
• Click any bookmark to open it in a new tab.
• Use the search bar to find any bookmark instantly.
• Switch tabs: All / Pinned / Recent / Open Tabs
• Click "＋ Add" to save the current page or any URL.
• Click the 🔄 sync button to re-import Chrome bookmarks.
• Click the ☀ theme button to pick from 11 color themes.

NOTE: This extension does NOT replace your new tab page.
The popup icon sits in your toolbar — click it anytime.
